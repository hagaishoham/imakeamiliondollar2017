חיבור לספוטיפיי

המערכת מייצרת RSS feed לכל ערוץ פודקאסט. את ה-RSS הזה צריך להגיש לספוטיפיי כדי שהפרקים יופיעו שם אוטומטית.

איך לחבר את הפודקאסט לספוטיפיי:

  1. צור ערוץ פודקאסט בלשונית "ערוצים"
  2. העתק את כתובת ה-RSS feed של הערוץ
  3. היכנס ל-Spotify for Podcasters
  4. בחר "הוסף פודקאסט קיים" (Add existing podcast)
  5. הדבק את כתובת ה-RSS feed
  6. ספוטיפיי יאמת את ה-feed ויתחיל לאנדקס את הפרקים
  7. כל פרק חדש שתוסיף יופיע בספוטיפיי אוטומטית!
